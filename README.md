# Estimación 29-N

Panel interactivo con una estimación de voto y escaños para las elecciones generales del 29 de noviembre de 2026, a partir de la preelectoral del CIS (estudio 3584) corregida por recuerdo de voto.

Análisis propio con datos públicos del CIS, resultados oficiales de la Junta Electoral Central (BOE) y el RD 806/2026. No es una encuesta propia ni una predicción oficial.
